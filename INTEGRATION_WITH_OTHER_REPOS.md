# Cross-Repository Learning Path

## Terraform repository
Use the Terraform learning repository to deepen IaC language, modules, state, AWS networking, ECS/EKS and enterprise patterns.

## EKS repository
Use the EKS learning repository for Kubernetes/EKS operations, networking, identity, observability, autoscaling, GitOps and incident response.

## This SAA repository
Use this repository for architecture requirements, service selection, Well-Architected trade-offs and certification scenarios.

## Combined capstone
**SAA requirements → Terraform AWS foundation → EKS/ECS workload → observability/security → failure drill → architecture defense → exam scenario.**
