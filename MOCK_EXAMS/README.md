# SAA-C03 Mock Exam System

Create timed sets without reusing questions immediately.

## Mock structure
- 65 questions
- 130 minutes
- mixed domains
- multiple-choice and multiple-response style
- mark uncertain questions
- review every incorrect answer

## Review metrics
Track by domain, service pair, scenario type and error reason. Do not treat a score as sufficient evidence of understanding.

## Error categories
- missed requirement
- service confusion
- networking mistake
- security mistake
- resilience mistake
- performance mistake
- cost mistake
- over-engineering
- under-engineering
- rushed reading
