# Day 1 — AWS Global Infrastructure

## Objectives
Understand Regions, Availability Zones, edge locations, fault domains and the shared responsibility model.

## Lab
1. Choose one AWS Region.
2. Inspect available AZs.
3. Create a simple architecture spanning two AZs on paper.
4. Identify what would fail if one AZ disappeared.

## Architecture drill
Design a web tier that survives one AZ failure.

## Evidence
- architecture diagram
- failure-domain explanation
- five service-selection questions
