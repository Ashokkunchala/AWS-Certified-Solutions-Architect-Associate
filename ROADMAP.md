# SAA-C03 Learning Roadmap

## Phase 1 — Foundations
AWS global infrastructure, Regions, Availability Zones, shared responsibility, Well-Architected Framework.

## Phase 2 — Security
IAM, roles, policies, Organizations, SCPs, KMS, Secrets Manager, Parameter Store, S3 security, VPC security.

## Phase 3 — Networking
VPC, subnets, routes, gateways, security groups, NACLs, Route 53, endpoints, VPN/hybrid, load balancers, CloudFront.

## Phase 4 — Compute
EC2, AMIs, instance selection, Auto Scaling, ELB, Lambda, containers and serverless patterns.

## Phase 5 — Storage
S3, lifecycle, versioning, replication, storage classes, EBS, EFS and backup/archive.

## Phase 6 — Databases
RDS, Aurora, Multi-AZ, read replicas, DynamoDB, ElastiCache and migration concepts.

## Phase 7 — Integration
SQS, SNS, EventBridge, Step Functions, API Gateway and asynchronous architecture.

## Phase 8 — Operations and governance
CloudWatch, CloudTrail, Config, Systems Manager, Organizations, budgets and audit.

## Phase 9 — Resilience, performance and cost
Scaling, caching, replication, RTO/RPO, DR strategies, right-sizing, pricing and network-cost patterns.

## Phase 10 — Architecture mastery
Design complete systems from requirements and defend every decision.

## Weekly rhythm
- 3 days learning + diagrams
- 2 days hands-on
- 1 day scenario drills
- 1 day timed questions + error review

## Completion standard
A topic is complete when you can explain it, compare alternatives, build it, break it, recover it and choose it correctly in a scenario.
